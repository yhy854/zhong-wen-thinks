# 中文思维链插件 (zhong-wen-thinks)

强制 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 里的 Agent
**用简体中文思考**。

模型的思维链默认往往是英文的。用户看着一屏英文推理，不知道自己钱花在哪、
模型到底在想什么。这个插件往系统提示词最靠前的位置插一段最高命令，
让全部推理、规划、工具调用分析都走中文。

## 安装

```bash
dsh plugin --profile <profile> add github:yhy854/zhong-wen-thinks
```

桌面版：设置 → 插件 → 从其他来源安装，填 `github:yhy854/zhong-wen-thinks`，
勾选「这是来自本地、Git 或其他外部来源的高级插件」，装完**重启 DSH**。

## 效果

装上后新开会话，思考块应该是中文的：

```
用户：帮我看看这个项目为什么构建失败

思考中：
  先看 package.json，确认 Node 版本要求。
  报错说是 ESM 导入问题，多半是 tsconfig 的 moduleResolution 没配对。
  我去读一下 tsconfig.json 验证这个猜测。
```

而不是满屏的英文推理。

## 注入位置

DSH 的系统提示词按固定顺序拼接：

```
-1000  HARNESS_IDENTITY            身份介绍
 -900  ← 本插件在这里
    0  DEPLOYMENT_PERSONA_PREFIX
  500  PLAN_POLICY
 1000  TOOL_BASH
 ...   各种工具说明
10200  DEPLOYMENT_PERSONA_SUFFIX
```

`-900` 是身份介绍之后、其他一切之前，是所有外部插件能插入的最靠前位置。
越靠前，模型越难忽略。

## 注入内容

完整的指令原文就在 `index.js` 的 `TEXT` 常量里，没有隐藏逻辑。要点：

- 定性为「最高命令」，优先于其他语言/格式指示
- 说明目的：保护用户体验，让用户看懂模型在想什么
- 枚举范围：思维链、计划、工具调用前后、自我检查、最终回答
- 防漂移：上下文里的英文是材料，不是你的语言
- 留例外：代码、命令、路径、变量名、报错原文保持原样

## 已知限制

1. **这是提示词约束，不是硬机制。** DSH 和 DeepSeek API 都没有「强制推理语言」的开关。
   提示词能最大化概率，但不保证 100%。工具返回大量英文内容后偶尔会漂移。
2. **两阶段锚定 preset 会过滤提示词段。** 如果你的 preset 首轮把提示词裁剪成只剩 persona，
   本插件的段同样会被裁掉，晋升后才恢复。
3. **`complete: true` 的段会覆盖整份提示词。** 如果有插件注册了完整提示词，你这段就不在结果里。
4. **准确率取舍。** 有研究指出，用提示词强制模型用非英语思考，可提升可读性与可监督性，
   但可能降低答案准确率。本插件的取舍是先看得懂。

## 想要确定的中文显示？

如果你的诉求是「界面上一律看到中文」而不在乎模型用什么语言思考，官方实验包
`@deepseek-ai/dsh-experimental-client-ui-cot-translation` 做的是**事后翻译**：
模型用英文想，界面上翻成中文显示，原文保留可切回。两者可以叠加使用。

> **直接静默禁用整行插件**，界面上却还显示 compatible。

## 零依赖

本插件不 `import` 任何 npm 包，只用 Cordis 注入的 `ctx.systemPrompt`。
这样从任意本地目录挂载都不会因为模块解析失败而拖垮整棵插件树。

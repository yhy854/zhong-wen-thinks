# 中文思维链插件 (zhong-wen-thinks)

**最适配中国宝宝体质的 DeepSeek Harness 原生中文思考插件！**

用 DeepSeek Harness 时，你是不是也受够了这种憋屈体验：明明用中文提问，最终回答也是中文，但中间长长一串思考过程全特么是英文！看着满屏飞速滚动的洋文，根本不知道模型到底在盘算什么、钱花在了哪；等它吭哧吭哧跑完几分钟吐出结果，才发现它从第一步就理解错了方向，时间与 Token 全白费。

装上这个插件，直接让模型用**「原生简体中文」**思考：

- **彻底告别英文盲盒**：从分析问题、拆解计划到调用工具，全程母语级中文推理，一眼扫过去全看懂。
- **苗头不对，随时打断纠错**：不用再傻傻干等最终结果！看着它思考时发现方向歪了、找错文件了，当场按下暂停补充一句，省时省钱省心。
- **真正的「原生思考」，不是事后机翻**：直接在系统提示词最顶层注入最高优先级母语指令，让模型从脑子里就用中文转弯，零延迟、零额外翻译开销。

## ⚡ 超级便捷，三步一键安装

不用折腾繁琐配置，直接用 DeepSeek Harness 官方插件面板三步搞定：

1. 打开 DeepSeek Harness 桌面端，点击左侧边栏的 **「插件」** 按钮；
2. 点击右上角 **「添加插件」**；
3. 填入下面任意一行，点击安装即可。

**npm 包名：**

```
zhong-wen-thinks
```

**GitHub 地址：**

```
https://github.com/yhy854/zhong-wen-thinks
```

装完按面板提示重启，**新开一个会话**就是中文思考了。

💡 **随开随关，丝滑掌控**：完全接入 DSH 官方插件管理，装好开启即用；平时想用就开，不需要时在插件面板随手一点就能关闭，干净利落。

## 为什么它这么稳？（技术细节）

### 1. 抢占 -900 黄金注入位

DSH 的系统提示词按固定序号拼接：

```
-1000  HARNESS_IDENTITY            身份介绍
 -900  ← 本插件直接插在这里（全场最前排！）
    0  DEPLOYMENT_PERSONA_PREFIX
  500  PLAN_POLICY
 1000  TOOL_BASH
 ...   各种工具说明
10200  DEPLOYMENT_PERSONA_SUFFIX
```

`-900` 紧贴在身份介绍之后、其他一切规则之前，是所有外部插件能拿到的最靠前位置。指令越靠前，模型的注意力权重越高，越难被后续长文冲淡。

### 2. 防英文漂移设计

完整指令就在 `index.js` 的 `TEXT` 常量里，没有任何暗箱逻辑：

- **最高指令定性**：明确要求中文思考优先级高于其他语言习惯。
- **全流程覆盖**：思维链、任务规划、工具调用前后的分析、自我检查全部锁定简体中文。
- **防英文传染**：专门警告模型「代码和报错里的英文只是原材料，读完必须切回中文思考」，大幅减少读完一堆英文日志后顺嘴飙英文的情况。
- **代码原样保留**：代码、命令、文件路径、变量名、报错原文严格保持原样，绝不瞎翻译导致命令报错。

### 3. 零外部依赖，绝不拖垮环境

本插件不 `import` 任何第三方 npm 包，纯粹使用 Cordis 注入的 `ctx.systemPrompt`。无论从哪个本地目录挂载，都不会因为模块解析失败而弄挂你的插件树。

## 实话实说：已知边界与取舍

我们不搞虚假宣传，以下几个客观边界请提前知晓：

1. **这是提示词强约束，不是底层硬锁死**：目前 DSH 与 DeepSeek API 都没有物理级别的「锁死推理语言」开关。本插件通过 `-900` 最高位提示词把中文思考概率拉到最高，但在连续吞入超大段纯英文日志后，仍偶发短暂漂移。
2. **两阶段锚定 Preset 的影响**：如果你的 Preset 首轮把提示词裁剪成只剩 Persona，本插件的段落首轮同样会被裁掉，进入后续阶段后恢复。
3. **`complete: true` 覆盖问题**：如果同时装了其他霸道覆写整份系统提示词（`complete: true`）的插件，本段指令会被覆盖。
4. **可读性与准确率的取舍**：学术界有研究指出，强制模型用非英语推理可能对部分极限理科题的准确率产生微小影响；但日常写代码、查 Bug、跑工程任务，「人能实时看懂、及时把方向盘抢回来」带来的效率提升，远远大于那点理论误差。

如果你既想要英文原生推理、又想界面显示中文：可以去试官方实验包 `@deepseek-ai/dsh-experimental-client-ui-cot-translation`（事后机翻展示），两者甚至可以叠加使用。
